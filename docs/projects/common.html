common

Shared Python components used for repository-wide compliance and permission tracking.

Current contents

  • bitbucket_permission_tracker.py provides structured permission violation reporting.
  • fs_meter_kernel_filtered.py streams kernel vfs_open events with in-kernel inode filtering, mount-namespace mismatch tagging, and billing metadata.
  • fs_meter_settings.json provides a runtime settings profile so deployments can override defaults without editing code.
  • deploy/systemd/fs-meter.service provides VM runtime automation for fs-meter.
